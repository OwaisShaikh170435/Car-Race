## How to Run

1. Clone the repository:
```
  https://github.com/OwaisShaikh170435/Car-Race/tree/main
```
2. Install the requirements:
```
   pip install pygame
```
   (For a web version, skip this step.)
3. Start the game:
```
   python main.py
```
   (For a web version, open `index.html` in your browser.)

## Controls

| Key | Action |
| --- | --- |
| ← / A | Move left |
| → / D | Move right |
| ↑ / W | Speed up |
| ↓ / S | Slow down |
| Esc | Pause / quit |

## How to Play

Steer your car to avoid obstacles and other vehicles. The longer you survive, the higher your score. The game ends if you crash.
